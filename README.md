# Full-dataset training on RunPod — RTX 4090 24 GB

This package trains **EfficientNet-B0 (CNN)** and **Swin-Tiny (Transformer)** using the complete
existing dataset inventory with the corrected v2 splits. It also downloads **SDXL Faces** as a
new held-out generator test. It does not create a pod or spend cloud funds by itself.

## Data plan

| Data | Images | Training role |
|---|---:|---|
| 140k Real and Fake Faces (FFHQ real + StyleGAN fake) | 140,000 | corrected train/val/test |
| DFDC frames | 50,000 | video-ID-disjoint train/val/test |
| DeepFakeFace | 120,000 | aligned filename variants share split |
| DF40 mirror train | 25,696 | already part of index_v2 (train only) |
| DF40 mirror val + test | 6,424 | external evaluation only |
| SDXL Faces (`8clabs/sdxl-faces`) | 1,920 | **new held-out generator; never train** |

The old index has 310,000 rows. The full available inventory including all DF40 mirror splits is
342,120 images. External SDXL adds 1,920 images that are evaluated separately and never counted
as training data.

## Recommended RunPod setup

- GPU: **RTX 4090 24 GB**
- Template: current official **RunPod PyTorch** image with a recent CUDA/PyTorch stack
- Persistent **network volume**, mounted at `/workspace`
- Suggested volume: **150–200 GB** for original data, caches, logs, and checkpoints
- Use a non-interruptible pod unless you understand spot termination and resume behavior.
- Storage and pod are billed separately. Check current RunPod rates before creation.

├── project/                  # this package (scripts/configs)

│   │   └── test_extracted/

`index_v2.csv` maps to the 224×224 cached images, not the original full-resolution folders.
The training loader still verifies every selected image can be opened; corrupt data stops training
rather than being silently substituted.

## Upload the package and data

1. Copy this package to `/workspace/project` on the network volume.
2. Copy the existing cache to `/workspace/data/cache`.
3. Copy DF40 `val_extracted` and `test_extracted` to `/workspace/data/df40_mirror`.
4. Copy `manifests/index_v2.csv` and `manifests/df40_external.csv` to `/workspace/data`.
5. Run setup and validation:

```bash
cd /workspace/project
bash scripts/setup_runpod.sh
python scripts/validate_data.py \
  --index /workspace/data/index_v2.csv \
  --df40-external /workspace/data/df40_external.csv \
  --sdxl-external /workspace/data/sdxl_external.csv \
  --check-files
```

## Start full training

```bash
cd /workspace/project
nohup bash scripts/run_all.sh > /workspace/logs/run_all.log 2>&1 &
tail -f /workspace/logs/run_all.log
```

The runner trains CNN first and Swin second. Four epochs maximum, with early stopping after two
non-improving validation epochs. AMP, channels-last, batch 128, and 12 data workers are configured
for the 4090; adjust `configs/full_training.json` if the pod template has fewer CPU/RAM resources.

## Resume after interruption

Checkpoints are saved to `/workspace/outputs/checkpoints`:
- `<model>_best.pt`: best validation AUC; used for final evaluation.
- `<model>_last.pt`: model + optimizer + scheduler + scaler + epoch/history for resume.

Restart with the same command; `--resume` is already included. History is also saved as JSON after
each epoch. Never delete or replace `index_v2.csv` between resume attempts.

## Outputs

For each model:
- Best and last checkpoints
- History JSON and final metrics JSON
- Per-image prediction CSVs for in-domain and external sets

Combined:
- `full_training_results.xlsx` — in-domain, external, per-source metrics
- `model_comparison.csv`, `external_comparison.csv`, `per_source_metrics.csv`
- `external_comparison.png`
- `REPORT.md`

## Scientific safeguards

- SDXL Faces is held out from training and checkpoint selection.
- DF40 val/test is external only; it must not be concatenated into the training index.
- DFDC video IDs have zero overlap across corrected train/val/test splits.
- DFF filename-aligned variants remain in the same split.
- Report accuracy, AUC, fake recall, real recall, F1, and per-source breakdown.
- Do not claim universal detection based only on external accuracy.
- SDXL Faces evaluates only SDXL faces; it is not evidence of performance on MidJourney, Flux,
  FaceApp, or every unseen generator.

Download `/workspace/outputs` before terminating the pod. Keep the volume if further evaluation or
